A calendar of fencing events in NSW.

Live at cianscalendar.com

This is an unofficial solo project I've made in part as a member of the community requiring a better calendar but also to build my engineering portfolio

The tool uses a local admin page where I can create events, either manually or through traditional/NLP scraping. 

Scrapers pull events currently from the Aus Fencing Federation (AFF) page and the NSW Fencing Association (NSWFA) site. 
The AFF scraping is done more traditionally without LLM assistance, as the events are consistently structured.
The NSWFA scraping is done with NLP AI to infer all the required details to create an event.

Everything lands in a pending queue for a human pass over and to fill missing details and to be notified if events may be duplicates.
Posts from social media can be pasted in as screenshots or text for the NLP agent to infer from.

Running it:

npm install
npm run admin         

The scrapers run from the admin page, or directly with npm run scrape:aff and npm run scrape:nswfa. The NSWFA one needs an ANTHROPIC_API_KEY environment variable. 

Layout
docs/       the site and data
admin/      the local admin tool
scrapers/   AFF and NSWFA scrapers, plus the AI reading
schema/     the event schema
scripts/    validation and the duplicate checks
tests/      tests


Hosting

The site is hosted on Cloudflare.


How AI was used:
For images and NSWFA events, AI LLM scrapers are used to search the event for details to fill the schema. 
Additionally, much of the code has been generated by Claude's Sonnet 5.5 model.
